# LeaLife 🌸

Application web progressive (PWA) d'organisation personnelle, planning, tâches et objectifs de vie.

## Fonctionnalités
- 📅 **Planning & Calendrier** : Suivi des événements et rendez-vous
- ✅ **Tâches** : Gestion des to-do quotidiennes et rappels
- 🎯 **Objectifs** : Suivi de projets personnels, stage, études, sport
- 👤 **Espace Personnel** : Profil, organisation et statistiques
- 📱 **PWA & Offline** : Prise en charge du mode hors ligne et installable sur mobile/desktop

## Installation et lancement

```bash
# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev

# Compiler pour la production
npm run build
```
